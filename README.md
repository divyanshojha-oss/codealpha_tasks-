# Web Development Projects

A collection of three beginner-friendly web development projects built with **HTML, CSS, and JavaScript**.

## Projects

### 1. Responsive Image Gallery
A photo gallery with a clean, responsive layout and interactive browsing features.

**Features**
- Responsive photo grid for desktop, tablet, and mobile
- Category filters: All Photos, Nature, City, and Ocean
- Hover effects and smooth transitions
- Lightbox view with next/previous navigation
- Keyboard controls: arrow keys to navigate and `Esc` to close

**Technologies:** HTML, CSS, JavaScript

### 2. Basic Calculator
A simple calculator for everyday arithmetic.

**Features**
- Addition, subtraction, multiplication, division, and modulo
- Decimal input, clear, delete, and sign-toggle buttons
- Chained calculations and result display
- Keyboard support
- Handles division-by-zero errors

**Technologies:** HTML, CSS, JavaScript

### 3. Personal Portfolio Website
A responsive portfolio template for presenting background, skills, projects, and contact details.

**Features**
- About, Skills, Projects, and Contact sections
- Responsive mobile navigation
- Smooth scrolling, hover effects, and reveal animations
- Project cards and contact links
- Responsive design for different screen sizes

**Technologies:** HTML, CSS, JavaScript

> **Personalize before publishing:** Replace the sample email address and profile links in the portfolio with your own details. Add a resume PDF if you want to include your resume.

## Run Locally

1. Clone or download this repository.
2. Open the folder in Visual Studio Code.
3. Open the project folder you want to try.
4. Open its `index.html` file in your browser, or use the **Live Server** extension in VS Code.
5. For the gallery's remote photos and Google Fonts, an internet connection is required.

No build tools or package installation are required.
